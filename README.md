# PlateMaker - 線画レリーフプレート作成Webアプリ

写真やイラストから線画を抽出し、**厚さ2mmの台座プレートの上に2mmの厚さで盛り上がった立体（合計4mm厚）**を生成・3Dプレビュー確認し、3Dプリンタ用の水密（Watertight）**STLファイル**をダウンロードできるWebアプリケーションです。
GitHubのPagesで公開して動作します。
---

## 主な機能

1. **写真・画像の入力**
   - ファイルのドラッグ＆ドロップ / ファイル選択
   - スマホやPCのカメラによる直接撮影
   - サンプル画像（花、猫、幾何学模様）での即時確認

2. **線画抽出エンジン（Canvas API）**
   - **輪郭抽出 (Sobelフィルタ)**: 写真の輪郭をくっきりエッジ検出
   - **局所適応 2値化 (Adaptive)**: 陰影や照明ムラのある写真から線画をきれいに抽出
   - **標準2値化 (Threshold)**: イラストや白黒スケッチ向け
   - **線の太さ調整**: モルフォロジー演算（膨張・収縮）により、かすれた細い線を太くして3Dプリントしやすくしたり、太い線を細く調整可能（-3 〜 +5）
   - 閾値、コントラスト、ぼかし、白黒反転のリアルタイム調整

3. **3Dモデル生成**
   - 台座厚さ 2.0 mm ＋ 線画盛り上がり厚さ 2.0 mm（合計4.0 mm）
   - 台座の形は 40mmx40mmの正方形、 直径40mmの丸、 40x40mmの釣鐘型、 40x40mmのハート形、 または線画の外側の輪郭から2mm外側に膨らんだ形で50x50mmの大きさ、を選択できる
   
4. ** & プレビュー (Three.js)** 
   - マウスドラッグによる360度回転、ズーム、パン
   - 上面視点／斜め視点リセットボタン
   - ワイヤーフレーム表示切り替え
   - 各種フィラメントカラー（ホワイト、ブラック、グレー、シルクゴールド等）での表示

5. **STLダウンロード機能**
   - 底面・側面が完全に閉じた水密（Watertight / Manifold）なバイナリSTLを出力
   - Cura, PrusaSlicer, Bambu Studioなどのスライサーソフトに直接読み込み可能

## 起動方法

```bash
# 依存パッケージのインストール
npm install

# 開発用ローカルサーバーの起動
npm run dev

# 本番ビルド
npm run build
```

ブラウザで `http://localhost:5173` を開いてご利用いただけます。
